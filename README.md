# 🥗 NutriAdvisor API

NutriAdvisor is a backend API service designed to provide intelligent, personalized nutritional analysis from food imagery. 

By leveraging Google's Gemini 2.5 Flash multimodal AI, the application accepts an image of a meal alongside specific user health goals (such as "muscle gain" or "weight loss") and dietary restrictions (like "vegan" or "gluten-free"). 

It processes this information to return a comprehensive, structured JSON breakdown that includes:
* **Food Detection:** Identification of individual items on the plate.
* **Nutritional Estimation:** Calculated estimates for total calories and macronutrients (protein, carbs, fat, fiber).
* **Goal-Oriented Scoring:** A health score from 1-10 evaluating how well the meal aligns with the user's specific objectives.
* **Actionable Advice:** Tailored recommendations and healthier ingredient swaps based on the provided dietary profile.

Ultimately, NutriAdvisor serves as the intelligent core for dietary tracking applications, turning simple photos into structured, actionable health data.
